# Simulador de heteroestructuras (versión web)

**Abrir:** https://scarlata0.github.io/simulador-heteroestructuras-web/

Simulador interactivo de polaritones plasmón–fonón en heteroestructuras de grafeno y dieléctricos polares,
basado en el formalismo de la matriz de interfaces D (TFG de Física). Funciona por completo en el navegador:
el motor de cálculo en Python (NumPy/SciPy) se ejecuta con Pyodide (WebAssembly), sin servidor y sin instalar nada.
La primera carga tarda unos 10–20 s.

Este repositorio solo contiene la web compilada.
